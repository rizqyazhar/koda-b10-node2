# Minitask

Membuat program interaktif dengan module readline Node.js untuk mengkonversi input format tanggal '24-04-2015' menjadi '24/04/2015'. Program disertai dengan validasi yang mana jika format input tidak sesuai akan mengembalikan message 'Format tanggal salah'.

Program dibuat dengan 2 versi. Versi menggunakan package moment dan versi tanpa external package.
